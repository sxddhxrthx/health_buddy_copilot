# NNNN: Decision title

- **Status:** Proposed
- **Issue:** Link the scoped issue.
- **Owner and reviewer:** Name the responsible humans.
- **Approval:** Link explicit human approval before marking Accepted.
- **Supersedes:** Link an earlier ADR if applicable, otherwise state none.

## Context and scope

Describe the problem, acceptance criteria, constraints, and explicit non-goals.

## Proposed decision

Explain the change and affected components/contracts. Identify existing boundaries it would change.

## Alternatives

Compare credible alternatives, including keeping the current implementation.

## Consequences and safety

Describe trade-offs, data flows, privacy/security implications, compatibility and operational costs.
For health-related changes, identify synthetic-only limitations and required human review gates.

## Validation and rollout

Specify tests, acceptance evidence, migration/rollback steps, and required platform/release checks.

## Documentation updates

List affected instructions, product plan, architecture, contracts and detailed guides.
